# Getting help

- **A question about installing or using Toft:** ask in
  [Discussions → Q&A](https://github.com/Nickpap21/toft/discussions/categories/q-a).
  Search there first, because someone may have asked already.
- **Something broken:** open a [bug report](https://github.com/Nickpap21/toft/issues/new?template=bug.yml)
  with the version and the steps to reproduce it.
- **An idea:** open a [feature request](https://github.com/Nickpap21/toft/issues/new?template=feature.yml),
  or start a discussion if it needs talking through first.
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md)
  describes. Never in public.

Toft is maintained by a small team, and support is best-effort, through the
channels above. There's no paid support yet.
